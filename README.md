# Mubis X HD — plugin de Kino (18+)

El catálogo para adultos (películas y canales en vivo) del mismo servidor **Xtream Codes** que [Mubis HD](https://github.com/xuper-plugin/mubis). Todo viene marcado como 18+, así que **Kino lo muestra solo con el código 18+ desbloqueado**.

## Instalar

En Kino: **Ajustes ▸ Plugins ▸ Agregar**, y escribe `xuper-plugin/mubis-x`. Kino muestra la hoja de consentimiento (a qué hosts llega y qué permisos pide) antes de instalar nada.

## Qué trae

- Inicio, exploración, búsqueda, episodios y descargas, más canales en vivo, todo detrás del código 18+ de Kino.
- La cuenta se guarda cifrada en el aparato con un secreto sellado que solo Kino puede abrir; el plugin solo funciona instalado desde la rama principal, sin `@rama`.

## Ajustes

- **Cuenta:** estado de la cuenta, **Probar conexión** y **Vaciar caché**.
- El video puede salir de otros hosts (`streamHosts: any`, `liveStreamHosts: any`; aviso en rojo al instalar).
